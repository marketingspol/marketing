# marketing - Sitio web profesional

Este paquete incluye un sitio web profesional de una sola página para una empresa de diseño llamada **marketing**.

## Contenido
- `index.html` – estructura principal del sitio.
- `styles.css` – diseño visual y estilos en colores blanco y azul.

## Secciones incluidas
- Hero principal
- Servicios
- Portafolio
- Planes / precios
- Proceso de trabajo
- Testimonios
- Formulario de contacto

## Estilo visual
- Fondo blanco
- Acentos azules
- Apariencia moderna y profesional
- Diseño responsive

## Uso
1. Descomprime el archivo ZIP.
2. Abre `index.html` en tu navegador.
3. Si deseas publicarlo, súbelo a GitHub Pages, Netlify o cualquier hosting estático.

## Personalización
Puedes editar fácilmente:
- Nombre de la empresa
- Textos
- Precios
- Colores
- Formulario de contacto
